# Правила работы со мной

## 1. Как объяснять
Я новичок в программировании. Отвечай по-русски, простыми словами, без жаргона.
Новые термины объясняй одной фразой.

## 2. Как давать задачи
У меня СДВГ, мне трудно начинать. Давай короткие шаги по одному.
В конце каждой задачи пиши: «Следующий маленький шаг: …».

## 3. О проекте
Проект — средневековая доска расследований для D&D.
- Весь код живёт в одном файле `index.html`, без сборки и без внешних библиотек.
- Сайт работает на GitHub Pages и должен открываться в планшете Tabletop Simulator.

## 4. Сохранённые доски
Не ломай сохранённые доски: если меняешь формат данных в localStorage,
сделай переход со старого формата.

## 5. Объём изменений
Меняй только то, о чём я попросил.
